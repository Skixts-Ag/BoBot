🤖 BoBot Expressive Desktop Companion Robot

BoBot is an ongoing personal engineering project that explores embedded systems, electronics, and human-machine interaction through a small, expressive desktop robot.

Built around the ESP32-C3 SuperMini, BoBot uses an OLED display to show facial expressions and responds to physical button interactions with animations, timer functionality, and sound effects.

✨ Features

* Expressive OLED facial animations
* Physical button-based interactions
* Built-in timer mode
* Passive buzzer for sound effects
* Offline operation for core functionality
* Compact and affordable electronics

🔧 Hardware

Component	Purpose
ESP32-C3 SuperMini	Main microcontroller
1.3-inch OLED display	Facial expressions and interface
Two push buttons	User interaction
Passive buzzer	Audio feedback
3.7 V LiPo battery	Portable power
Charging module	Battery charging

🎯 Project Goal

The goal of BoBot is to transform a simple microcontroller project into a compact, expressive robotic companion while developing practical skills in hardware design, embedded programming, prototyping, and system integration.

The project is being developed iteratively, with each version introducing new features and engineering improvements.
